## 📂 Featured projects

### 🤖 Chat Bot: Natural-Language Data Assistant
An analytical assistant that lets users ask questions about organizational data in plain Portuguese and get back summaries, insights, tables and charts.
**Stack:** `Python` `FastAPI` `PostgreSQL` `RAG` `Docker`
- Turns questions into SQL (NL2SQL), guided by retrieved context about the data model
- Built with safety in mind: read-only access and query validation before anything runs
- Conversation history with follow-up questions, plus PDF and CSV export
- Demo mode with simulated data · *Proof of concept*


### 📦 ERP / Stock Management System
Full-stack system to manage inventory, sales and finances in one place.
**Stack:** `Vue.js` `Python` `MySQL`
- Stock control with automatic updates on every movement
- Sales and financial tracking
- Marketplace integration in progress


### 🇧🇷 Socioeconomic Impact on Criminality in Brazil
Data science project on how socioeconomic factors relate to crime rates across Brazil.
**Stack:** `Python` `Pandas` `Scikit-learn` `PostgreSQL` `Docker` `Metabase`
- Public safety, population, education and IDHM datasets combined in a PostgreSQL data warehouse
- KPIs and dashboards for crime and socioeconomic indicators
- Machine learning baseline to explore crime rate prediction
